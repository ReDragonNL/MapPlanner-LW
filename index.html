MapPlanner - Help & Instructions

📱 Basic Operations

  • Modes: Choose between Draw, Select, and View using buttons in the top toolbar
  • Draw Mode: Tap/click to place X blocks (bases) on the grid
  • Select Mode: Tap/click to select items, drag to move them, lasso-select by dragging on empty space
  • View Mode: Pan the canvas by dragging (no selection or drawing)
  • Zoom: Use mouse wheel, pinch gesture, or the zoom slider
  • Mobile: Double-tap a Point to edit it

🎨 Drawing Tools (DTools)

  • + Element: Add preset elements like Alliance Center, Mountain, Lake, etc.
  • + Custom: Add a custom point at the center of the view
  • Edit Custom: Edit properties of selected point (size, color, label, image, etc.)
  • Lock/Unlock: Toggle lock status to prevent accidental movement
  • Light Base: Toggle selected X blocks to Y blocks (light sources) and vice versa
  • Align H/V: Auto-arrange selected X blocks horizontally or vertically with custom spacing
  • Delete: Remove selected items
  • Copy/Paste: Duplicate selected items
  • Clear All: Remove everything from the canvas (cannot be undone separately)

⚙️ Menu Options

  • Grid Size: Change grid dimensions (20-2000). Enter size and click "Apply"
  • Measure Tool: Click to measure distance between two tiles (shows tile count)
  • Auto-Save: Enable to automatically save your work to browser storage every 30 seconds
  • Load Auto-Save: Restore the last auto-saved session
  • Save/Load JSON: Export and import your entire map as a JSON file
  • Export PNG: Download canvas as image (includes legend at bottom)
  • Export CSV: Export item data as spreadsheet-compatible CSV
  • Toggle Theme: Switch between Dark and Light color schemes
  • Stats Overlay: Show FPS counter and item statistics

⌨️ Keyboard Shortcuts

  • Ctrl+Z / Ctrl+Y: Undo / Redo
  • Ctrl+C / Ctrl+V: Copy / Paste selected items
  • Delete or Backspace: Delete selected
  • F: Fit view to show all content
  • Esc: Deselect all items
  • Ctrl+A: Select all items
  • Ctrl+Shift+C: Clear all
  • ?: Show/hide this help overlay

🎨 Legend & Colors

  • Color Button: Apply colors to selected X/Y blocks
  • Legend Panel: Shows all colors used in your map
  • Edit Labels: Click any legend color to add a custom label
  • Auto-Numbering: X and Y blocks are automatically numbered based on their position and color

📍 Points (Custom Elements)

  • Size: Set custom width and height for each point
  • Label: Add text label (displayed in center)
  • Colors: Customize fill color, area glow color, borders
  • Transparency: Control opacity of fill, area, and borders separately
  • Area Glow: Toggle glowing radius around point
  • Image Overlay: Upload custom image to display on point
  • Lock: Prevent accidental movement when locked

💡 Tips & Tricks

  • Fast Drawing: In Draw mode, hold and drag to paint multiple blocks
  • Multi-Select: In Select mode, drag across empty space to lasso-select multiple items
  • Collision Prevention: Items cannot overlap - the app will find nearby free space automatically
  • Zoom Anywhere: Scroll wheel zooms toward mouse cursor position
  • Touch Gestures: Use two-finger pinch to zoom, two-finger drag to pan
  • Fit View: Press 'F' or click "Fit View" to frame all content perfectly
  • Right Click: Context menu in Select mode for quick actions

🔧 Troubleshooting

  • Can't place items: Check if area is occupied. Try smaller grid size or fit view first
  • Can't move items: Make sure you're in Select mode. Check if item is locked
  • Lost your work: Click "Load Auto-Save" if auto-save was enabled
  • Performance issues: Reduce grid size or zoom level. Hide stats overlay
  • Touch not working: Ensure you're using a supported browser (Chrome, Safari, Firefox)
